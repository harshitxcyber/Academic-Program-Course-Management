# Academic Program & Course Management System (SQL)

##  Project Overview

The Academic Program & Course Management System is a SQL-based database project designed to manage academic programs and their associated courses in a structured and centralized manner.

The database maintains organized records of academic programs such as BBA and MBA, along with the subjects offered under each program. It aims to improve data accuracy, consistency, data integrity, and accessibility through relational database management.

##  Problem Statement

Managing academic programs and their associated courses using unstructured or disconnected data can lead to data redundancy, inconsistencies, and difficulties in retrieving academic information.

This project addresses these challenges by developing a structured relational database using SQL, ensuring efficient storage, organization, and management of academic program and course information.

##  Project Objectives

- Develop a centralized database for managing academic programs and courses.
- Organize program and course information using relational database concepts.
- Apply database normalization to minimize data redundancy.
- Establish relationships between academic programs and courses.
- Maintain data accuracy and integrity using SQL constraints.
- Enable efficient retrieval and management of academic information.

##  Database Components

The project focuses on two primary entities:

### 1. Program Table
Stores information about academic programs, including program identifiers and program names.

Examples:
- Bachelor of Business Administration (BBA)
- Master of Business Administration (MBA)

### 2. Course Table
Stores information about individual courses or subjects offered under different academic programs.

The course records are associated with their respective programs through relational database relationships.

##  SQL Implementation

The project involves the following database development activities:

- **Data Cleaning:** Preparing and organizing the collected academic dataset.
- **Database Normalization:** Structuring program and course data to reduce redundancy.
- **Table Creation:** Creating separate relational tables for programs and courses.
- **Primary Keys:** Establishing unique identifiers for records.
- **Foreign Keys:** Maintaining relationships between programs and courses.
- **Data Management:** Organizing academic information for efficient retrieval.
